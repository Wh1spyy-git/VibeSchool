# VibeSchool

Android-приложение для удобного просмотра данных ученика из «Сетевого города. Образование».

## Текущий этап

Создан первый демонстрационный каркас интерфейса:

- Android 8.0+ (`minSdk 26`);
- Jetpack Compose и Material 3;
- экраны расписания, дневника и калькулятора среднего балла;
- корректный расчёт взвешенного среднего;
- расчёт количества пятёрок с весом 1 до желаемого среднего;
- состояние офлайн-кэша предусмотрено в модели интерфейса;
- демонстрационные данные изолированы за интерфейсом `SchoolRepository`.

Интеграция авторизации через ЕСИА/СГО, зашифрованное хранение сессии, PIN/отпечаток и реальный офлайн-кэш будут добавляться следующими этапами. Пользователь вводит данные Госуслуг только на официальной странице авторизации; приложение не должно читать или сохранять логин и пароль ЕСИА.

## Сборка

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat testDebugUnitTest assembleDebug
```

Debug APK после сборки находится в `app/build/outputs/apk/debug/app-debug.apk`.
