# VibeSchool

Android-приложение для удобного просмотра данных ученика из «Сетевого города. Образование».

## Текущий этап

Создан первый рабочий каркас интерфейса:

- Android 8.0+ (`minSdk 26`);
- Jetpack Compose и Material 3;
- экраны расписания, дневника, калькулятора среднего балла и настроек;
- плавные переходы между разделами и единая сетка размеров;
- сохраняемая персонализация: светлая/тёмная/системная тема, четыре палитры,
  динамические цвета Android, три варианта скруглений и компактный режим;
- настройки отображения кабинетов, домашних заданий и анимаций;
- выбор любого доступного предмета в калькуляторе;
- встроенный вход ученика через официальные страницы СГО/Госуслуг без перехода в Chrome;
- распознавание возврата в `/app/diary`, перехват сессии СГО и её шифрование через Android Keystore;
- корректный расчёт взвешенного среднего;
- расчёт количества пятёрок с весом 1 до желаемого среднего;
- состояние офлайн-кэша предусмотрено в модели интерфейса;
- источник школьных данных изолирован за интерфейсом `SchoolRepository`.

До подключения импорта приложение показывает честные пустые состояния без демонстрационных уроков и оценок. Вход проходит во встроенном окне только по HTTPS на разрешённых доменах `*.edu22.info` и `*.gosuslugi.ru`. После возврата в дневник приложение сохраняет cookie-сессию СГО в зашифрованном виде; логин и пароль ЕСИА приложение не читает и не сохраняет. Загрузка данных из СГО, PIN/отпечаток и реальный офлайн-кэш будут добавляться следующими этапами.

## Сборка

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat testDebugUnitTest assembleDebug
```

Debug APK после сборки находится в `app/build/outputs/apk/debug/app-debug.apk`.
